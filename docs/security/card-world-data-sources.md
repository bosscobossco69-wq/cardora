# TRIXOVEL card world source review (preview)
- Pokémon: https://tcgdex.dev/faq and https://github.com/tcgdex/cards-database (database MIT license; no publisher endorsement). Existing API integration unchanged, names and identifiers only.
- One Piece: selected factual OP-01 names and printed numbers checked against https://en.onepiece-cardgame.com/cardlist/ and https://exploretcgsets.com/onepiece/sets/op-01/. No scraping, card text, prices, or card images. The public OPTCG API https://www.optcgapi.com/documentation permits application requests without an API key, but live CI confirmed valid JSON and Access-Control-Allow-Origin: * for OP01-001. The response uses card_set_id and card_name (including a printed-number suffix). Preview uses exact OP set code queries only, normalizes names, filters exact matching codes, caps results and caches them locally for 24 hours. Name searches remain limited to the starter index. Do not claim complete coverage.
- Yu-Gi-Oh!: https://ygoprodeck.com/api-guide/ public free API; use bounded explicit user-initiated GET search, omit credentials/referrer, cache normalized metadata in browser for 24h (max 25 query pages), no hotlinking, copyrighted effect text or pricing. Sample passcodes checked against API exact-name responses. Live CI confirmed valid JSON and Access-Control-Allow-Origin: * for Dark Magician. Commercial reuse rights beyond factual metadata must still be confirmed before production.
- Existing reference category art is illustrative and not official card art, stock, or evidence of publisher permission. Commercial publication of existing art remains a separate unresolved clearance item.
- All new collections are local to origin/device, per-game, capped, and user-entered variants marked unverified. No account, payment, admin or database changes. No new paid plan.
