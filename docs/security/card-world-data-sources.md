# TRIXOVEL card world source review (preview)
- Pokémon: https://tcgdex.dev/faq and https://github.com/tcgdex/cards-database (database MIT license; no publisher endorsement). Existing API integration unchanged, names and identifiers only.
- One Piece: selected factual OP-01 names and printed numbers checked against https://en.onepiece-cardgame.com/cardlist/ and https://exploretcgsets.com/onepiece/sets/op-01/. No scraping, card text, prices, or card images. The public OPTCG API https://www.optcgapi.com/documentation permits application requests without an API key, but actual endpoint response could not be verified during this review. Not connected. Starter index is not exhaustive. Do not claim complete coverage.
- Yu-Gi-Oh!: https://ygoprodeck.com/api-guide/ public free API; use bounded explicit user-initiated GET search, omit credentials/referrer, cache normalized metadata in browser for 24h (max 25 query pages), no hotlinking, copyrighted effect text or pricing. Sample passcodes checked against API exact-name responses. CORS/browser live availability and commercial reuse rights beyond factual metadata must still be confirmed before production.
- Existing reference category art is illustrative and not official card art, stock, or evidence of publisher permission. Commercial publication of existing art remains a separate unresolved clearance item.
- All new collections are local to origin/device, per-game, capped, and user-entered variants marked unverified. No account, payment, admin or database changes. No new paid plan.
