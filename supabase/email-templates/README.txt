Cardora-branded Supabase Auth email template drafts.

These files are drafts only; the current HTML source did not contain server-side auth email templates. They have NOT been uploaded to Supabase.

Before use:
1. Review each template and replace/verify placeholders against the current Supabase Auth email template documentation and your project's redirect URLs.
2. In Supabase Dashboard > Authentication > Email Templates, paste each HTML template into its matching template.
3. Configure approved production Site URL and redirect URLs; do not point production email links at localhost or an unverified domain.
4. Test signup confirmation, recovery, magic link, email change and invite flows in a separate test account.
5. Set a verified sender/domain and review anti-abuse limits.

Brand/domain check: these templates say Cardora but do not assume that a Cardora domain is registered or verified.
